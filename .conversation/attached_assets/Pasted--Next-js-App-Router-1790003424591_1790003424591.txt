Создай архитектуру и техническую логику для интерактивного учебного веб-сайта на Next.js (App Router) + TypeScript.

ОБЩИЕ ТРЕБОВАНИЯ:
- Язык пользовательского интерфейса и всех учебных данных: КАЗАҚША.
- Технические идентификаторы, названия типов, полей, компонентов и шагов состояния могут оставаться на английском.
- Аудитория: Ученики 7 класса (история Казахстана).
- Проект полностью клиентский (Frontend-only), БЕЗ подключения внешних API (OpenAI и др.) и БЕЗ использования бэкенда/localStorage.
- Вся информация хранится в локальном файле данных data.ts.

1. СТРУКТУРА ДАННЫХ (data.ts):
Создай тип данных QuestionData и массив данных минимум из 10 вопросов (по 2 вопроса на тему).

7-сыныпқа арналған 5 тақырып:
1. Тәуке хан
2. Ақтабан шұбырынды
3. Әбілқайыр хан
4. Бөгенбай батыр
5. Бұқар жырау

Каждый элемент массива должен иметь следующую структуру:
{
  id: number;
  topicId: string;
  topicTitle: string; // Тақырып атауы қазақ тілінде
  question: string; // 7-сыныпқа арналған тарихи сұрақ
  aiAnswer: string; // ЖИ-дің демонстрациялық жауабы
  textbookAnswer: string; // 7-сынып Қазақстан тарихы оқулығынан демонстрациялық мәтін
  similarities: string[]; // Сәйкес келетін фактілер тізімі
  differences: string[]; // Айырмашылықтар тізімі
  textbookOnly: string[]; // Тек оқулықтағы фактілер
  aiOnly: string[]; // Тек ЖИ жауабындағы фактілер
  pointsToCheck: string[]; // Қосымша тексеруді қажет ететін тұстар
  similarityPercentage: number; // Сәйкестік пайызы (мысалы, 75)
  differencePercentage: number; // Айырмашылық пайызы (мысалы, 25)
  analysis: string; // Қорытынды бейтарап талдау
  modelPath: string; // Болашақ 3D-модельге жол (мысалы, "/models/tauke-khan.glb")
}

Добавь в код комментарий:
// DEMO DATA — заменят реальные выдержки из учебников и ответы ИИ.

2. СОСТОЯНИЕ И ПОЛЬЗОВАТЕЛЬСКИЙ СЦЕНАРИЙ (React State Flow):
Приложение должно управляться единым состоянием на React (useState):
- currentTopicId: выбранная тема
- currentQuestionId: выбранный вопрос
- currentStep: текущий экран/шаг исследования

Шаги исследования (пошаговый мастер):
1. 'landing' (Басты бет)
2. 'topics' (5 тақырыптың бірін таңдау)
3. 'question-select' (Таңдалған тақырып бойынша сұрақты таңдау)
4. 'question-intro' (Таңдалған сұрақты көру)
5. 'ai-answer' (ЖИ жауабын көру)
6. 'textbook-answer' (Оқулықтағы жауапты көру)
7. 'comparison' (Екі дереккөзді салыстыру: сол жақта — ЖИ, оң жақта — оқулық)
8. 'analysis' (Қорытынды талдау: сәйкестік графиктері мен тармақтарды қарастыру)
9. 'final' (Статистикасы бар зерттеуді аяқтау экраны)

3. АРХИТЕКТУРА И КОМПОНЕНТЫ:
- Создай главный компонент-контроллер, который переключает экраны на основе currentStep.
- Реализуй кнопки навигации («Келесі», «Сұрақтар таңдауының бетіне оралу», «Қайта бастау»), которые корректно меняют состояние.
- Создай компонент-заглушку HistoryObject3DPlaceholder, принимающий modelPath, который временно отображает аккуратный информационный блок, готовый к будущей интеграции React Three Fiber / Three.js.

Сгенерируй чистый, масштабируемый TypeScript-код Next.js с логикой переключения шагов и полным локальным массивом data.ts на казахском языке. Пользователь видит только казахский текст: заголовки, кнопки, подсказки, сообщения, вопросы и все учебные данные. Технические идентификаторы и комментарии в коде могут быть на английском.
